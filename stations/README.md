# Senderlisten / Station lists

## Deutsch

Fertige Listen für den Tab *Webradio*. Im Tab oben bei *Liste von GitHub laden* den Namen eintragen (zum Beispiel `aac-auswahl`) oder die Datei herunterladen und mit *Liste laden* einlesen. **Das Laden ersetzt die ganze Senderliste**; vorher mit *Liste speichern* sichern.

| Datei | Inhalt |
|---|---|
| `mp3-auswahl` | 30 beliebte deutsche Sender als MP3 (Stand der Firmware 1.4.0) |
| `aac-auswahl` | 15 Sender als AAC/HE-AAC (Radio Hamburg, Regenbogen, Energy Berlin, Absolut Relax, Heavy Metal, 80er und weitere) |
| `rock` | 7 Sender für Rock und Klassiker |
| `entspannung` | 8 Sender für Ruhe, Klassik und Chillout |

Alle Streams waren beim Anlegen erreichbar (die AAC-Sender zusätzlich auf dem Gerät abgespielt). Sender ändern ihre Adressen von Zeit zu Zeit; ein toter Eintrag lässt sich im Tab ersetzen.

## English

Ready-made lists for the *Webradio* tab. Enter the name (for example `aac-auswahl`) at *Liste von GitHub laden* at the top of the tab, or download the file and read it in with *Liste laden*. **Loading replaces the whole station list**; save it first with *Liste speichern*.

| File | Content |
|---|---|
| `mp3-auswahl` | 30 popular German stations as MP3 (state of firmware 1.4.0) |
| `aac-auswahl` | 15 stations as AAC/HE-AAC (Radio Hamburg, Regenbogen, Energy Berlin, Absolut Relax, Heavy Metal, 80s and more) |
| `rock` | 7 stations for rock and classics |
| `entspannung` | 8 stations for calm, classical and chillout |

All streams were reachable when the lists were made (the AAC stations were also played on the device). Stations change their addresses from time to time; a dead entry can be replaced in the tab.
