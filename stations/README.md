# Senderlisten / Station lists

## Deutsch

Fertige Listen für den Tab *Webradio*. Im Abschnitt *Senderlisten* bei *Fertige Liste* eine Liste wählen und *Von GitHub laden* drücken, oder die Datei herunterladen und mit *Liste laden* einlesen. **Das Laden ersetzt die ganze Senderliste**; vorher mit *Liste speichern* sichern. RSA wird nur dann vorn eingetragen, wenn die Senderliste vorher leer war; bei allen Änderungen danach wird er nicht wieder eingetragen (die Listen hier enthalten ihn nicht). Vorn stehen deine Favoriten (Tab *Webradio*), dann die Sender der Liste ohne Doppelte; was über die 30 Plätze hinausgeht, entfällt.

Die Auswahl im Tab stammt aus der Datei `index.txt` in diesem Ordner (eine Zeile je Liste: `name|Beschreibung deutsch|Beschreibung englisch`). **Eine neue Liste braucht kein neues Flashen:** Datei `name.txt` und eine Zeile in `index.txt` auf GitHub ablegen, dann erscheint sie nach dem Neuladen der Seite. Ohne Internet im Browser bleiben die vier ersten Listen im Auswahlfeld.

## English

Ready-made lists for the *Webradio* tab. In the section *Senderlisten* pick a list at *Fertige Liste* and press *Von GitHub laden*, or download the file and read it in with *Liste laden*. **Loading replaces the whole station list**; save it first with *Liste speichern*. RSA is put at the front only if the station list was empty before; with all changes after that it is not entered again (the lists here do not contain it). Your favorites (*Webradio* tab) come first, then the stations of the list without duplicates; whatever exceeds the 30 slots is dropped.

The selection in the tab comes from the file `index.txt` in this folder (one line per list: `name|description German|description English`). **A new list needs no new flashing:** put the file `name.txt` and one line in `index.txt` on GitHub, and it appears after the page is reloaded. Without internet in the browser the first four lists stay in the selection field.
